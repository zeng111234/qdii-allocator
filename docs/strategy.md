# 策略权重体系

## 概述

QDII基金投资系统支持4种分配策略：

1. **equal** - 平均主义
2. **low_fee** - 低费率优先
3. **scarce** - 稀缺额度优先
4. **dynamic** - 智能动态（推荐）

## 1. 平均主义 (equal)

**逻辑：** 预算平均分配给所有可申购基金。

**适用场景：**
- 无偏好，分散投资
- 简单易懂

**示例：**
- 预算100元，3只基金
- 每只分配约33元

## 2. 低费率优先 (low_fee)

**逻辑：** 管理费低的基金优先买满。

**适用场景：**
- 长期持有
- 注重成本控制

**示例：**
- 基金A费率0.5%，限额100
- 基金B费率1.5%，限额100
- 预算100元 → 全部买A

## 3. 稀缺额度优先 (scarce)

**逻辑：** 限购额度小的基金优先买（稀缺货）。

**适用场景：**
- 额度紧张
- 想买稀缺品种

**示例：**
- 基金A限额10元
- 基金B限额100元
- 预算100元 → 先买A 10元，再买B 90元

## 4. 智能动态 (dynamic) - 推荐

**逻辑：** 综合评分排名，TopN推荐。

### 评分权重体系

```javascript
WEIGHTS = {
  base: 10,                    // 基础分
  
  // 长期因子（核心）
  yearReturn: 0.2,            // 1年收益率
  threeYearReturn: 0.15,      // 3年累计收益
  sharpeRatio: 4.5,           // 夏普比率（重要）
  maxDrawdown: 0.15,          // 最大回撤惩罚
  longTermBull: 3.0,          // 长期牛市加分
  longTermBear: -4.0,         // 长期熊市扣分
  stabilityBonus: 2.5,        // 稳定收益加分
  
  // 中期因子
  drawdown: 2.0,              // 近期回撤
  maDeviation: 1.5,           // MA10偏离
  trendBonus: 2.0,            // 多头排列加分
  trendPenalty: -2.5,         // 空头排列扣分
  momentumReversal: 2.0,      // 反弹信号
  
  // 短期因子
  recent5Change: -0.3,        // 5日涨跌
  volatility: -0.5,           // 波动率惩罚
  
  // 辅助因子
  historicalSuccess: 1.0,     // 历史成功率
  feePenalty: -0.8,           // 费率惩罚
  rotationPenalty: -0.8,      // 连续推荐惩罚
  premiumPenalty: -3.0,       // 溢价>3%惩罚
  scarcityBonus: 2.0,         // 限购加分
  unknownPenalty: -3.0,       // 信息未知惩罚
  suspended: -999             // 暂停申购
}
```

### 评分逻辑

#### 长期因子（权重最高）

1. **夏普比率** (权重4.5)
   - 风险调整后收益
   - 夏普1.5 → +6.75分
   - 夏普0.5 → +2.25分

2. **1年收益率** (权重0.2)
   - 涨20% → +4分
   - 跌10% → -2分

3. **3年累计收益** (权重0.15)
   - 累计60% → +3分
   - 累计-30% → -1.5分

4. **最大回撤** (权重0.15)
   - 回撤-40% → -6分
   - 回撤-10% → -1.5分

#### 中期因子

1. **近期回撤** (权重2.0)
   - 回撤10% → +20分（抄底机会）
   - 新高 → 扣分

2. **MA偏离** (权重1.5)
   - 低于MA10 → 加分（低估）
   - 高于MA10 → 扣分（高估）

3. **趋势强度**
   - 多头排列 → +2分
   - 空头排列 → -2.5分

#### 短期因子（权重最低）

1. **5日涨跌** (权重-0.3)
   - 短期波动不应主导决策

2. **波动率** (权重-0.5)
   - 高波动扣分

#### 辅助因子

1. **限购加分** (权重2.0)
   - 限购10元 → +20分（稀缺信号）

2. **溢价惩罚** (权重-3.0)
   - 溢价>3% → 扣分

3. **连续推荐惩罚** (权重-0.8)
   - 避免过度轮换

### 排名逻辑

1. 按评分排序
2. 取TopN（默认3）
3. 应用轮换规则（避免连续推荐同一只）
4. 分配预算

## 策略对比

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| equal | 简单分散 | 无差异化 | 新手入门 |
| low_fee | 成本低 | 可能错过高收益 | 长期持有 |
| scarce | 买稀缺品 | 可能买贵 | 额度紧张 |
| dynamic | 智能优化 | 复杂 | 推荐使用 |

## 最佳实践

1. **新手**：先用 `scarce` 策略熟悉系统
2. **进阶**：切换到 `dynamic` 策略
3. **定期**：每周回测验证策略效果
4. **调整**：根据回测结果优化权重
