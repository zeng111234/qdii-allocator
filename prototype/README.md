# QDII Fund Allocator - Design System v2.0

## 优化概述

本原型是对原始 `docs/index.html` 的设计优化版本，主要目标是消除 AI Slop 特征，提升专业度和品牌感。

## 设计改进

### 1. 配色系统
- **移除**：紫罗兰渐变 (`#6366f1` → `#8b5cf6`)
- **新增**：专业深蓝配色 (`#1a56db` / `#0f172a`)
- **优化**：暗色主题配色一致性

### 2. 字体系统
- **新增**：Inter 字体 (Google Fonts)
- **保留**：系统字体作为 fallback
- **优化**：字体层级清晰 (h1/h2/h3)

### 3. 圆角系统
- **建立**：6 级圆角层次体系
  - `--radius-xs: 4px` (小标签)
  - `--radius-sm: 6px` (按钮、标签)
  - `--radius-md: 8px` (卡片、输入框)
  - `--radius-lg: 12px` (大卡片、模态框)
  - `--radius-xl: 16px` (特色元素)
  - `--radius-full: 9999px` (药丸形)

### 4. 交互状态
- **新增**：`focus-visible` 焦点样式
- **新增**：`active` 按压反馈
- **新增**：`disabled` 禁用状态
- **优化**：`hover` 状态层次感

### 5. 响应式断点
- **新增**：3 个关键断点
  - Mobile: `max-width: 640px`
  - Tablet: `min-width: 768px`
  - Desktop: `min-width: 1024px`
- **优化**：Tab 可横向滚动 (移动端)
- **优化**：网格布局自适应

### 6. 动效增强
- **新增**：Tab 切换动画 (`fadeIn`)
- **新增**：详情展开动画 (`slideDown`)
- **优化**：Toast 通知过渡
- **优化**：减少动效偏好支持

### 7. Emoji 替换
- **移除**：所有 UI 中的 emoji 图标
- **替换**：专业文字标签或图标系统
- **保留**：数据中的 emoji (如适用)

## 使用方法

### 方法 1：直接使用
1. 在浏览器中打开 `prototype/index.html`
2. 所有功能均可正常交互

### 方法 2：集成到构建流程
1. 将 `prototype/index.html` 复制为 `docs/index.html.template`
2. 运行 `node build-pages.js`
3. 生成优化后的 `docs/index.html`

## 技术细节

### CSS 变量系统
所有颜色、间距、圆角均使用 CSS 变量，便于主题切换和维护。

### 动画性能
仅使用 `transform` 和 `opacity` 进行动画，避免触发 layout/paint。

### 可访问性
- 键盘导航支持 (`focus-visible`)
- 减少动效偏好 (`prefers-reduced-motion`)
- 足够的触摸目标尺寸 (≥44px)
