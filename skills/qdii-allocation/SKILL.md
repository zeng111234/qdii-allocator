## QDII 基金定投分配技能

### 核心原则
1. **目标配置优先**：只向低配风险桶投入，不因短期涨跌提高预算
2. **限购只做路由**：限购额度不是品质信号，额度用尽后才切换同指数通道
3. **同指数合并**：多个基金代码不增加分散度，同一 `indexGroup` 按一个敞口计算
4. **费率敏感**：同类基金优先数据新鲜、跟踪稳定、总费率较低的现有通道

### 分配策略
- **三级决策**：风险桶 → 指数组 → 现有基金通道
- **每周预算**：常规上限250元；择时信号暂停时核心桶上限50元/周、20元/日
- **硬风控**：未同步、净值过期、未知持仓或风险锚点回撤达到-10%时预算为0
- **战术暂停**：只允许美股宽基、非美和防御低配桶的小额定投，成长科技预算为0

### 基金选择标准
| 指标 | 权重 | 说明 |
|------|------|------|
| 夏普比率 | 高 | 风险调整后收益，>1.0 为优秀 |
| 1年收益 | 中 | 长期表现验证 |
| 最大回撤 | 中 | 控制下行风险 |
| 跟踪稳定度 | 中 | 同指数通道120日相对稳定性 |
| 总费率 | 中 | 同类优先较低费率 |
| 限购额度 | 无质量权重 | 只决定执行通道路由 |

### 注意事项
- QDII 基金通常按有效申请日净值成交，T+2主要是确认时间
- 溢价 >3% 时暂停买入
- 暂停申购的基金保留观察，等待恢复
